# Week 8 Day 1 — React Lifecycle

This app demonstrates React class component error boundaries, update lifecycle
methods, and unmounting.

## Run the app

From this directory:

```sh
npm install
npm run dev
```

Use the displayed local URL to open the exercises. Click each counter five
times to compare shared, individual, and missing error boundaries. The
Lifecycle section changes the favorite color after mounting and includes a
button for removing the child component.

Run `npm run build` to verify the production build.
